# SHIKI™ VPM Repository

このリポジトリを GitHub Pages の `master` ブランチのルートから公開します。

- `vpm.json`: VCC が読むパッケージ一覧。ページの見た目を変更するときは編集しません。
- `index.html`: インストール案内と Avatar Transmute の紹介。
- `assets/css/vpm.css`: VPM ページ固有の配置。
- `assets/css/style.css`, `assets/js/`, `assets/svg/`: SHIKI™ Avatar Tools のホームページと共通のテーマ、設定、ロゴ、アイコン。

ホームページの共通アセットを更新したときは、VPM 側の `assets/` に同じファイルを反映してください。インストールリンクと手動登録 URL は `vpm.json` を指しています。
