SHIKI Avatar Tools

Unityでのアバター制作・変換をサポートするツールを配布しています。

VCCに追加

VRChat Creator CompanionをインストールしたPCで、 次のボタンを押してください。

SHIKI Avatar ToolsをVCCに追加
  1. ブラウザでVCCを開くことを許可します。
  2. VCCでリポジトリの追加を確認します。
  3. 対象プロジェクトのManage Projectからツールを追加します。

β版を利用する場合は、VCCのSettings → Packagesで Show Pre-Release Packagesを有効にしてください。

ボタンで追加できない場合

VCCのSettings → Packages → Add Repositoryに、 以下のURLを入力してください。

Avatar Transmute

アバターの診断・軽量化・VRM 0.x／1.0変換を行う Unity Editor拡張です。

  • メッシュ削減や隠れ面削除による軽量化
  • 表情・揺れ物・コライダーの変換
  • lilToonからMToonへのマテリアル変換
  • 他のEditor拡張から利用できる公開API

β版です。導入前にプロジェクトをバックアップし、 変換結果を確認してください。
